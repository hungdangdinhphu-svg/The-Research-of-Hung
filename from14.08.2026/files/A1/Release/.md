# Comparing and Totally Ordering Mathematical Expressions: Is the Traditional Process Redundant?

Hung Dinh Phu Dang

## Abstract 

I call this the "classic processing workflow":


$$\text{Expressions} \xrightarrow{\text{Arithmetic Computation}} \text{Scalar Values} \xrightarrow{\text{Comparison}} \text{Relational Structure and "Spacing between expressions"
} (<, >, =)$$

Observing the center: In many applications, the final scalar value is not what is truly needed; rather, what matters is the relative ordering or distance between expressions. Here, the scalar value merely serves as an intermediate "carrier" for that relational information.
